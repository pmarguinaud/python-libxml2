# xml_libxml API reference

Generated by `docs/make_api.py` from the docstrings. The Perl documentation of
XML::LibXML describes what each method does; `docs/migration.md` says how the
Python forms differ.

## Module functions

- `load_xml`: Parse XML with the given options: string=, location= or IO=.
- `load_html`: Parse HTML with the given options: string=, location= or IO=.
- `createDocument`: New document: (version, encoding) or (uri, name, dtd)
- `load_catalog`: Load a catalog, for all parsers
- `externalEntityLoader`: Set the loader of all external entities, and return the previous one
- `callbacks`: Get the four global callbacks, or set them. They apply to all parsers.
- `match_callback`: Get or set the global match_callback.
- `open_callback`: Get or set the global open_callback.
- `read_callback`: Get or set the global read_callback.
- `close_callback`: Get or set the global close_callback.
- `encodeToUTF8`: Text from bytes in this encoding.
- `decodeFromUTF8`: Bytes in this encoding from text.
- `HAVE_READER`: True: the Reader is always built, as in Perl.
- `HAVE_SCHEMAS`: True: RelaxNG and Schema are always built, as in Perl.
- `HAVE_STRUCT_ERRORS`: True: errors are always Error objects, as in Perl.

Constants: `HTML_PARSE_NOERROR`, `HTML_PARSE_RECOVER`, `LIBXML_VERSION`, `XML_ATTRIBUTE_DECL`, `XML_ATTRIBUTE_NODE`, `XML_CDATA_SECTION_NODE`, `XML_COMMENT_NODE`, `XML_DOCUMENT_FRAG_NODE`, `XML_DOCUMENT_NODE`, `XML_DOCUMENT_TYPE_NODE`, `XML_DTD_NODE`, `XML_ELEMENT_DECL`, `XML_ELEMENT_NODE`, `XML_ENTITY_DECL`, `XML_ENTITY_NODE`, `XML_ENTITY_REF_NODE`, `XML_HTML_DOCUMENT_NODE`, `XML_NAMESPACE_DECL`, `XML_NOTATION_NODE`, `XML_PARSE_COMPACT`, `XML_PARSE_DTDATTR`, `XML_PARSE_DTDLOAD`, `XML_PARSE_DTDVALID`, `XML_PARSE_HUGE`, `XML_PARSE_NOBASEFIX`, `XML_PARSE_NOBLANKS`, `XML_PARSE_NOCDATA`, `XML_PARSE_NODICT`, `XML_PARSE_NOENT`, `XML_PARSE_NOERROR`, `XML_PARSE_NONET`, `XML_PARSE_NOWARNING`, `XML_PARSE_NOXINCNODE`, `XML_PARSE_NSCLEAN`, `XML_PARSE_OLD10`, `XML_PARSE_OLDSAX`, `XML_PARSE_PEDANTIC`, `XML_PARSE_RECOVER`, `XML_PARSE_SAX1`, `XML_PARSE_XINCLUDE`, `XML_PI_NODE`, `XML_TEXT_NODE`, `XML_XINCLUDE_END`, `XML_XINCLUDE_START`.

`xml_libxml.ErrNo` has the error codes of libxml2 (`ERR_*`, ...), as Perl's ErrNo.
`xml_libxml.Common` has the node type names of XML::LibXML::Common.
